# JavaScript Warm-Up — Task Tracker

A task tracker with a beautiful UI and dead buttons. Your job: write the JavaScript that makes it work.

## Quick Start

**1. Fork this repo** — Click the **Fork** button at the top right of this page.

**2. Clone your fork:**
```bash
git clone https://github.com/YOUR-GITHUB-USERNAME/fpp-js-playground.git
cd fpp-js-playground
```

Open `index.html` in your browser (right-click → Open With), or use **Live Server** in VS Code. No npm needed.
