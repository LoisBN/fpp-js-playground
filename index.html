    function addTask() { // Step 1: Find the input box and get its text const input = document.getElementById("task-input"); const text = input.value.trim(); // Step 2: If nothing was typed, stop here if (text === "") return; // Step 3: Create a new task and add it to the array tasks.push({ id: nextId++, title: text, completed: false }); // Step 4: Clear the input box input.value = ""; // Step 5: Refresh the screen renderTasks(); }
    📖 Line by line
    document = the web page itself. It's how JavaScript "sees" and interacts with HTML.

    document.getElementById("task-input")
    → "Hey document, find me the element with id="task-input""
    → Returns the input box so we can read what the user typed

    .value → the text currently inside the input box
    .trim() → removes spaces from start/end (so " hello " becomes "hello")

    tasks.push({...}) → adds a new object to the end of the tasks array
    nextId++ → uses the number, then increases it by 1 for next time
    if (condition) return; is a common pattern. It says "stop here if something is wrong" — like checking if the input is empty before adding a task.
    if (text === "") return; // Stop if empty
    An object is a container with labeled values. Each task is an object with id, title, and completed. You create objects with curly braces { }.
    { id: 1, title: "Buy milk", completed: false }
    Mission 2: Toggle tasks complete. Find the toggleTask(id) function. When a checkbox is clicked, this function receives the task's id.
    What it should do
    1. Find the task with the matching id
    2. Flip its completed status
    3. Call renderTasks()
    Try this with Claude Code first!
    Fill in the toggleTask(id) function in playground.js. It should find the task by id in the tasks array, flip task.completed, and call renderTasks().
    Copy this prompt and paste it into Claude Code. Then check the solution below!
    function toggleTask(id) { // Find the task with this id const task = tasks.find(t => t.id === id); // Flip: true becomes false, false becomes true task.completed = !task.completed; renderTasks(); }
    📖 Line by line
    tasks.find(t => t.id === id)
    → Searches through the tasks array
    → t => t.id === id is a mini-function that checks: "does this task's id match?"
    → Returns the first task that matches

    task.completed = !task.completed
    → ! means "not" — it flips the value
    → If it was true, it becomes false. If false, becomes true.
    A boolean is either true or false. The completed property uses a boolean to track if a task is done or not.
    true
    Task is done
    false
    Task is not done
    The ! operator flips a boolean. !true becomes false, and !false becomes true. Perfect for toggling!
    task.completed = !task.completed; // Flip it!
    Mission 3: Delete tasks. Find the deleteTask(id) function. When the × button is clicked, this receives the task's id.
    What it should do
    1. Find the position of the task in the array
    2. Remove it
    3. Call renderTasks()
    Try this with Claude Code first!
    Fill in the deleteTask(id) function in playground.js. It should find the index of the task with that id using findIndex, remove it with splice, and call renderTasks().
    Copy this prompt and paste it into Claude Code. Then check the solution below!
    function deleteTask(id) { // Find the position (index) of this task const index = tasks.findIndex(t => t.id === id); // Remove 1 item at that position tasks.splice(index, 1); renderTasks(); }
    📖 Line by line
    tasks.findIndex(t => t.id === id)
    → Like find(), but returns the position number (0, 1, 2...)
    → We need the position to remove the item

    tasks.splice(index, 1)
    → splice(where, howMany) removes items from an array
    → index = start at this position
    → 1 = remove 1 item
    → Think of it like pulling a card out of a deck
    An array is a list of items. The tasks variable is an array that holds all your task objects. Arrays use square brackets [ ].
    const tasks = [ task1, task2, task3 ]; // A list!
    Arrays count from 0, not 1. The first item is at index 0, the second at index 1, etc. To remove an item, you need to know its position.
    index 0
    "A"
    index 1
    "B"
    index 2
    "C"
    Mission 4: Filter tasks. Find the setFilter(filter) function. When a filter tab is clicked, this receives "all", "active", or "completed".
    What it should do

    2. Call renderTasks()
    Try this with Claude Code first!

    function setFilter(filter) { currentFilter = filter; renderTasks(); }
    📖 That's it!
    This one is short because the filtering logic already lives inside renderTasks() (Section 2). When you change currentFilter and re-render, the function checks which tab is active and shows only matching tasks.
    const = value never changes (like tasks array reference). let = value can change (like currentFilter which switches between "all", "active", "completed").
    const
    Use for things that stay the same
    let
    Use for things that change
    A string is text wrapped in quotes. The filter values "all", "active", and "completed" are all strings.
    currentFilter = "completed"; // A string!
