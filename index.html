    🔄 How It Works

    Every interactive app follows this pattern:

    📦 Data changes → 🎨 renderTasks() → 🖥️ Screen updates

    When you add a task, the data changes. Then renderTasks() reads the data and redraws the list. That's it!

    Mission 1: Make the Add button work. Find the addTask() function in playground.js. It's empty! You need to fill it in.
    What it should do
    1. Get the text from the input box
    2. If empty, do nothing
    3. Add a new task to the array
    4. Clear the input
    5. Call renderTasks()
    function addTask() { // Step 1: Find the input box and get its text const input = document.getElementById("task-input"); const text = input.value.trim(); // Step 2: If nothing was typed, stop here if (text === "") return; // Step 3: Create a new task and add it to the array tasks.push({ id: nextId++, title: text, completed: false }); // Step 4: Clear the input box input.value = ""; // Step 5: Refresh the screen renderTasks(); }
    📖 Line by line
    document.getElementById("task-input") — finds the text box on the page
    .value.trim() — gets the typed text and removes extra spaces
    tasks.push({...}) — adds a new item to the end of the array
    nextId++ — uses the current number, then adds 1 for next time

    Mission 2: Toggle tasks complete. Find the toggleTask(id) function. When a checkbox is clicked, this function receives the task's id.
    What it should do
    1. Find the task with the matching id
    2. Flip its completed status
    3. Call renderTasks()
    function toggleTask(id) { // Find the task with this id const task = tasks.find(t => t.id === id); // Flip: true becomes false, false becomes true task.completed = !task.completed; renderTasks(); }
    📖 Line by line
    tasks.find(t => t.id === id) — searches the array for the task whose id matches
    !task.completed — the ! means "not". If it was true, it becomes false, and vice versa
    💬 Ask Claude: "Write a toggleTask(id) function that finds the task by id in the tasks array, flips task.completed, and calls renderTasks()."
    Mission 3: Delete tasks. Find the deleteTask(id) function. When the × button is clicked, this receives the task's id.
    What it should do
    1. Find the position of the task in the array
    2. Remove it
    3. Call renderTasks()
    function deleteTask(id) { // Find the position (index) of this task const index = tasks.findIndex(t => t.id === id); // Remove 1 item at that position tasks.splice(index, 1); renderTasks(); }
    📖 Line by line
    tasks.findIndex(t => t.id === id) — like find(), but returns the position number (0, 1, 2...) instead of the task itself
    tasks.splice(index, 1) — removes 1 item at that position. Think of it like pulling a card out of a deck.
    💬 Ask Claude: "Write a deleteTask(id) function that finds the index of the task with that id using findIndex, removes it with splice, and calls renderTasks()."
    Mission 4: Filter tasks. Find the setFilter(filter) function. When a filter tab is clicked, this receives "all", "active", or "completed".
    What it should do
    1. Set the currentFilter variable
    2. Call renderTasks()
    function setFilter(filter) { currentFilter = filter; renderTasks(); }
    📖 That's it!
    This one is short because the filtering logic already lives inside renderTasks() (Section 2). When you change currentFilter and re-render, the function checks which tab is active and shows only matching tasks.
